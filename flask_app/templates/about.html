About this project

Laptop Price Predictor

This project predicts laptop prices based on specifications like brand, processor, RAM, storage, display, and GPU. The data was scraped from Vijay Sales, cleaned, and used to train a Linear Regression model.

Tech Stack

  • Python, Pandas, NumPy
  • scikit-learn (preprocessing pipeline + Linear Regression)
  • Flask (backend + API)
  • Matplotlib & Seaborn (exploratory data analysis)
  • Plotly (interactive visualizations on the web app)
